Setup & Integration Guide

1. How to Run Locally

Simply save the code as index.html and open it directly in any web browser. No npm install or complex build pipeline required.

2. Customizing Projects & Screenshots

To update project photos, replace project placeholder headers with standard <img src="..." /> elements or live links in the Projects section.

3. Connecting Contact Form to Email Backend

To receive form submissions in your email inbox, connect Formspree or EmailJS by updating the form tag:

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">

4. Secure External AI API Setup

The floating portfolio chatbot runs on a lightweight rule-based JavaScript engine. To connect an external LLM (OpenAI/Gemini API), route requests through a secure serverless backend function (Node.js/Cloudflare Workers) and keep API keys confidential.
